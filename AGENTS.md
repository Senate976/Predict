# Préférences de l'utilisateur

L'utilisateur est novice en développement : explique les choses simplement,
sans jargon technique inutile (ou explique le jargon si tu dois l'utiliser).

Autonomie : tu peux faire toutes les actions nécessaires (modifier des
fichiers, committer, pousser sur la branche) sans demander confirmation à
chaque étape. Seule exception : toujours attendre un « ok » explicite avant
de merger une pull request.
